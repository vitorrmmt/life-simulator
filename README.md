# Life Simulator

Life Simulator feito em Java para fins de estudo e prática de programação orientada a objetos.

O projeto está em uma **versão de testes e desenvolvimento**, então algumas funcionalidades ainda podem mudar ou não estar implementadas.

## Tecnologias

* Java
* NetBeans
* Git / GitHub

## Estrutura

* `Main.java` — inicia o jogo
* `Jogo.java` — controla o jogo
* `Pessoa.java` — características e ações da pessoa
* `Eventos.java` — eventos do jogo

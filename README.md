# Life Simulator

Life Simulator feito em Java para estudar e praticar **Programação Orientada a Objetos**.

A ideia do projeto é criar um simulador de vida onde uma pessoa pode trabalhar, ganhar dinheiro, criar relações, passar por eventos e ter diferentes acontecimentos durante sua vida.

O projeto ainda está em desenvolvimento e muita coisa pode mudar conforme eu for desenvolvendo.

## Tecnologias

* Java
* NetBeans
* Git / GitHub

## Estrutura

* `Main.java` — inicia o jogo
* `Jogo.java` — controla o jogo
* `Pessoa.java` — representa uma pessoa e seus atributos
* `Emprego.java` — representa os empregos
* `GerenciaEmprego.java` — controla contratação e demissão
* `Relacoes.java` — representa as relações entre pessoas
* `GerenciaRelacoes.java` — controla as relações
* `Eventos.java` — eventos que acontecem durante o jogo

## Atualmente

O projeto já possui a estrutura inicial de:

* Pessoas
* Atributos como inteligência, saúde, dinheiro e idade
* Empregos
* Contratação e demissão
* Relações entre pessoas
* Tipos de relação utilizando `enum`

Ainda estou desenvolvendo a estrutura do simulador e adicionando novas funcionalidades aos poucos.

## Objetivo

O principal objetivo desse projeto é praticar Java e POO criando algo que vá ficando maior conforme eu aprendo novos conceitos.
